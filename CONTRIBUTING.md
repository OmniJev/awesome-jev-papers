# Contributing

This list holds research papers only: arXiv preprints, conference and journal papers, and technical reports. Code repositories, model pages, demos and blog posts go in [Awesome JEV](https://github.com/OmniJev/awesome-jev-gallery) instead.

## What belongs here

A paper belongs here when Jev, or a model with Jev's shape (declared options in, one calibrated probability per option out, no generated text), is the subject, the method, or a measured system. The Foundations section holds earlier papers that the System One idea builds on or is measured against.

## Entry format

One line per paper, newest first within its section:

```md
- [Short name](https://arxiv.org/abs/XXXX.XXXXX), "Full paper title". ![arXiv](https://img.shields.io/badge/arXiv-XXXX.XXXXX-B31B1B?style=flat-square)
```

Add a code badge when the paper links an official repository, and a Daily Papers badge when the paper has a Hugging Face Daily Papers page. Copy both from an existing entry.

## Checks

- The title matches the arXiv page exactly.
- The paper is about Jev or a Jev-shaped model, not another use of the letters JEV.
- The counts in the header badges, the contents and the news line still match the list.
